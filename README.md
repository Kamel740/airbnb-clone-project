# Airbnb Clone Project

This project is a full-stack clone of the popular accommodation booking platform, Airbnb.

The goal is to build a functional web application that allows users to browse property listings, view detailed property information, and complete bookings.

## Learning Objectives

* Implement responsive UI/UX designs from a Figma mockup.

* Understand how to structure a complex web application.

* Develop skills in a component-based frontend architecture using React.

* Practice working in a team with defined roles and responsibilities.

* Learn best practices for version control, code organization, and documentation.

## Tech Stack

* **Frontend:** HTML, CSS, JavaScript (React)

* **Version Control:** Git and GitHub

* **Design Tools:** Figma

---

## UI/UX Design Planning

### Design Goals

* Create an intuitive and seamless booking flow for users.

* Maintain visual consistency with the provided Figma design.

* Ensure fast page loading times for a better user experience.

* Prioritize a mobile-first, responsive design.

### Key Features

* Property search and filtering functionality.

* A detailed view for each property.

* A secure and simple checkout process.

* User authentication (Sign up/Log in).

### Primary Pages

| Page                    | Description                                                                    |
| :---------------------- | :----------------------------------------------------------------------------- |
| **Property Listing View** | A grid display of available properties with filtering options.                 |
| **Listing Detailed View** | Shows complete property details, including images, description, and a booking form. |
| **Simple Checkout View** | A streamlined page for payment and booking confirmation.                       |

### Importance of User-Friendly Design

A well-designed booking system is crucial because it reduces friction in the user journey, which directly leads to higher conversion rates and improved customer satisfaction.

Clear navigation, an intuitive interface, and responsive design ensure the platform is accessible and easy to use on any device.

### Figma Design Specifications

#### Color Styles

* **Primary:** `#FF5A5F`

* **Secondary:** `#008489`

* **Background:** `#FFFFFF`

* **Text:** `#222222`

* **Secondary Text:** `#717171`

#### Typography

* **Primary Font:** 'Circular', Medium (500), 16px

* **Headings:** 'Circular', Bold (700), 24px-32px

* **Secondary Text:** 'Circular', Book (400), 14px

### Importance of Identifying Design Properties

Identifying specific design properties like colors and typography from a mockup is essential for translating a design into code accurately.

It ensures **visual consistency** across the entire application, speeds up the development process by creating a clear style guide, and guarantees the final product perfectly matches the designer's vision.
